# Aktien-Chart (PWA)

Interaktiver Aktienchart (SpaceX, Tesla, Siemens, Petrobras, Gold) für das Handy.
Live: https://explorationse.github.io/aktien-app/

Kursdaten werden per GitHub Actions (Cron alle 5 Minuten, GitHub kann verzögern) von Yahoo Finance abgerufen
und zusammen mit der statischen Seite auf GitHub Pages veröffentlicht. Keine Anlageberatung.
